# Storage Estimator - Main version

A simple Python program that estimates how much storage space is needed for a set of files.

## Purpose

This project was created for **CS-117 Introduction to ICT (Lab 10 and Lab 11)**. The program takes the number of files and the average size of each file, then calculates the total storage required. The repository also demonstrates basic version control with Git and GitHub: commits, branches, Pull Requests, code review, and merge-conflict resolution.

## Requirements

- Python 3.8 or newer
- No external libraries needed

## How to Run

1. Open a terminal in the project folder.
2. Run the program:

   ```
   python storage_estimator.py
   ```

3. Enter the values when prompted.

## Example Input / Output

**Input**

```
Enter number of files: 5
Enter average file size (MB): 20
```

**Output**

```
Total storage needed: 100 MB
Total storage needed: 0.10 GB
```

> Note: the exact wording of the prompts and output may differ slightly depending on your version of the program.
